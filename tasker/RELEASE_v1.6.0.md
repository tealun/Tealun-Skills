# Tasker v1.6.0 — Strategy Recovery & Bounded Initiative

Tasker now strengthens proactive execution without weakening scope control.

## Added

- Bounded Initiative for inspecting the credible impact surface while keeping optional findings out of the change set
- Strategy Reset Protocol for replacing repeated variations with evidence-driven, materially different attempts
- Resumable blocked reports with exact evidence, ruled-out explanations, required external action, and a restart point
- Implementation Review covering plan alignment, contract safety, boundary behavior, and root-fix quality
- Progressive disclosure: recovery, verification, and delegation details now load only when their triggers apply
- A compact execution trace that demonstrates sequencing without restoring a full always-loaded example

## Preserved

- The seven-stage state machine and S/M/L sizing
- Acceptance gates, retry caps, and retreat rules
- No Overreach, KISS, and YAGNI boundaries
- Evidence Ledger, Outcome Path, and evidence-calibrated completion verdicts

## Behavioral Change

Repeated failure now triggers a hypothesis and strategy reset before another attempt. Proactive discovery is triaged into required, optional, and unrelated findings so that completeness does not become silent scope expansion.

The main skill file now keeps only high-frequency decisions and hard constraints; specialized protocols live in directly linked reference files.
