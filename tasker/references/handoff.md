# Delegation Handoff

Read this file only before proposing or preparing delegation.

Delegate only when the task is `L`, exceeds single-agent capacity, and a suitable installed capability exists. Match by capability rather than inventing a tool or skill name.

## Preconditions

Complete `intake`, `clarify`, and `plan` first. Delegation does not replace understanding the parent task.

Define:

- `parent_goal`
- `parent_constraints`
- `subtask_scope`
- `forbidden_paths`
- `done_definition`
- `validation_method`
- `tasker_depth`

Ask the user before switching workflows when delegation changes the execution path or requires new authority.

## Handoff Artifact

Write `tasker_handoff.md` in the workspace only after delegation is approved. Keep it factual and scoped:

```markdown
# Tasker Handoff

parent_goal: ...
parent_constraints: ...
subtask_scope: ...
forbidden_paths: ...
done_definition: ...
validation_method: ...
tasker_depth: ...
current_evidence: ...
```

The receiving workflow may treat these fields as established facts but must clarify missing or conflicting information. Delegated work remains subject to the parent's scope and acceptance requirements.
